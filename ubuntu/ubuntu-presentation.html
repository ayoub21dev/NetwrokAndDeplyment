What is Ubuntu?

📖

Ubuntu is a free and open-source operating system (OS) based on Linux.

It is an alternative to Windows and macOS.

💰

Free

100% free, no license required

🔓

Open Source

Source code is open to everyone

🛡️

Secure

Less vulnerable to viruses
